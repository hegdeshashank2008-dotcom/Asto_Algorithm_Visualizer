PROJECT ON: Asto_Algorithm_Visualizer
This project demonstrates how the A* algorithm finds a path from a starting point to a destination while avoiding obstacles.

 Key Features:
-  Interactive grid with start and destination points
-  Ability to place and remove obstacles
-  Step-by-step visualization of the search process
-  Visualization of the final path
-  Uses the A* algorithm to find an efficient route
 Technologies Used:
- Python
- Turtle Graphics
- heapq for priority-based node selection
One of the key concepts behind this project is the A* evaluation function:

f(n) = g(n) + h(n)

It combines the cost of reaching a node with the estimated cost of reaching the destination.
